### 主流开源 RAG 框架对比

| 框架 | 定位 | 协议 | GitHub Stars | 技术栈 | UI | 适用场景 |
|------|------|------|--------------|--------|-----|---------|
| **[Dify](https://github.com/langgenius/dify)** | LLM 应用开发平台 | Apache-2.0（附加条件） | 90k+ | Python + React | ✅ 完整 Web UI | 企业级 LLM 应用、RAG + Agent + Workflow |
| **[FastGPT](https://github.com/labring/FastGPT)** | 知识库 QA 系统 | Apache-2.0 | 20k+ | TypeScript + Next.js | ✅ 完整 Web UI | 知识库问答、文档检索、智能客服 |
| **[MaxKB](https://github.com/1Panel-dev/MaxKB)** | 企业级智能体平台 | GPLv3 | 15k+ | Python (Django) + Vue | ✅ 完整 Web UI | 智能客服、企业知识库、教育 |
| **[RagFlow](https://github.com/infiniflow/ragflow)** | 深度文档理解 RAG 引擎 | Apache-2.0 | 35k+ | Python + React | ✅ 完整 Web UI | 复杂文档解析、表格/图表理解 |
| **[Anything-LLM](https://github.com/Mintplex-Labs/anything-llm)** | 全功能 AI 桌面应用 | MIT | 35k+ | JavaScript + Electron | ✅ 桌面应用 UI | 个人/小团队文档问答、本地部署 |
| **[Flowise](https://github.com/FlowiseAI/Flowise)** | LangChainJS 可视化构建器 | Apache-2.0 | 35k+ | TypeScript + Node.js | ✅ 拖拽式 UI | 快速原型、LangChain 工作流 |
| **[Langflow](https://github.com/langflow-ai/langflow)** | Python LangChain 可视化构建器 | MIT | 50k+ | Python + React | ✅ 拖拽式 UI | Python 生态、LangChain 工作流 |
| **[n8n](https://github.com/n8n-io/n8n)** | 工作流自动化 + AI | Fair-code（非 OSI） | 60k+ | TypeScript + Node.js | ✅ 完整 Web UI | 自动化工作流、集成 + AI |
| **[Haystack](https://github.com/deepset-ai/haystack)** | NLP 框架 | Apache-2.0 | 18k+ | Python | ⚠️ 需自建 UI | 生产级 NLP 管道、搜索引擎 |
| **[LangChain](https://github.com/langchain-ai/langchain)** | LLM 应用框架 | MIT | 100k+ | Python / TypeScript | ❌ 无 UI（代码优先） | 自定义 LLM 应用、复杂工作流 |
| **[LlamaIndex](https://github.com/run-llama/llama_index)** | 数据框架 | MIT | 40k+ | Python / TypeScript | ❌ 无 UI（代码优先） | 数据连接、索引构建 |
