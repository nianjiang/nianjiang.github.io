### Comparison of HA Strategies

| Feature| Redis Sentinel     | Redis Cluster         | Note |
| --------          | --------   | -------   | --------     | 
| Best For    | High availability with a single master.     | Scaling large datasets across multiple masters.     |      |
| Failover    | Automatic (Sentinel promotes a slave).     |  Automatic (Nodes agree on promotion).    |      |
| Client Support   | Requires Sentinel-aware client.     |  Requires Cluster-aware client.    |      |
| GitHub Example    | [spotahome/redis-operator](https://github.com/spotahome/redis-operator) | [bitnami/redis-cluster](https://github.com/bitnami/charts/tree/main/bitnami/redis-cluster) |      |
