# CRI

### Tools
| Name | Doc | Github | Note |
| :--- | :--- | :--- | :--- |
| [containerd](https://containerd.io/) | [Docs](https://github.com/containerd/containerd/blob/main/docs/getting-started.md) | [Github](https://github.com/containerd/containerd)| 行业标准的容器运行时，强调简单、健壮和可移植性，可管理容器的完整生命周期。 |
| [runc](https://github.com/opencontainers/runc) | [Docs](https://manpages.debian.org/unstable/runc/runc.8.en.html) | [Github](https://github.com/opencontainers/runc) | OCI (Open Container Initiative) 规范的命令行客户端，用于根据规范生成和运行容器。 |
| [Docker](https://www.docker.com/) | [Docs](https://docs.docker.com/) | [Github](https://github.com/docker) | 最广为人知的容器平台，提供完整的容器化解决方案，包含构建、分享和运行应用的工具。 |
| [CRI-O](https://cri-o.io/) | [Docs](https://cri-o.io) | [Github](https://github.com/cri-o/cri-o) | 一个轻量级的、专门为 Kubernetes 设计的容器运行时，实现了 Kubernetes CRI (Container Runtime Interface) 接口。 |
