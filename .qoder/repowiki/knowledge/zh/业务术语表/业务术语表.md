### K8s Releases
- 定义：Kubernetes 版本发布信息表，记录各版本的发布时间、End of Life 日期及对应 Release Doc 链接，用于跟踪 Kubernetes 生命周期和支持状态。
- 别名：k8s版本表、Kubernetes版本列表

### Codes Structure
- 定义：Kubernetes 各组件的入口文件映射表，列出 kube-apiserver、kube-controller-manager、kube-scheduler、kubelet、kube-proxy 等核心组件的 Cobra Client 入口文件和实际实现文件路径。
- 别名：k8s源码结构、组件入口映射

### Aggregator Server
- 定义：Kubernetes API Aggregation Layer，允许第三方扩展 API 通过聚合层注册到主 API Server，通过 apiserver-builder 等工具开发自定义 API 服务器。
- 别名：API聚合服务器、聚合层

### CRD
- 定义：Custom Resource Definition，Kubernetes 自定义资源定义，允许用户扩展 Kubernetes API 以管理自定义资源类型，是 Operator 模式的基础。
- 别名：自定义资源定义、Custom Resource Definition

### Code Learn Turorial
- 定义：Kubernetes 源码学习资源集合，包含官方开发指南、社区教程、视频课程、源码分析文章等，用于深入理解 Kubernetes 内部实现。
- 别名：源码学习资源、k8s源码教程
