    Tools #

    NameDocGithubNote
    DifyDocGithub开源的 LLM 应用开发平台，集成 RAGPipeline 和工作流编排，非常适合快速落地 AI 项目。
    n8nDocGithub强大的工作流自动化工具，支持节点式编程，常用于 AI Agent 的业务逻辑集成。
    CozeDocN/A字节跳动推出的 AI 聊天机器人开发平台，支持丰富的插件和多模态能力（闭源但社区生态极强）。
    FlowiseDocGithub基于 LangChain 的可视化拖拽界面，适合构建定制化的 LLM 链和 Agent。
    LangflowDocGithub另一个主流的 Python 原生可视化编排工具，与 LangChain 生态深度绑定。
    MLflowDocGithub传统的 MLOps 标配，专注于实验追踪、模型打包和版本管理。
    BentoMLDocGithub统一的模型分发和部署框架，支持 GPU 推理优化，是模型上线阶段的关键工具。
    框架DocGithub核心概念主要优势典型应用场景Note
    AutoGenDocGithub对话的智能体 (Conversable Agent)自动化多智能体对话流，高度可定制的交互模式。自动化代码生成与测试、模拟产品开发流程。Python
    AgentScopeDocGithub消息传递 (Message Passing)易用性强，工程化程度高，支持分布式部署。构建复杂、可运维的大规模多智能体应用。Python
    CAMELDocGithub角色扮演 (Role-Playing)极简的协作设定，通过初始提示驱动自主对话。探索性任务、创意生成、模拟特定领域专家协作。Python
    LangGraphDocGithub状态图 (State Graph)天然支持循环和条件分支，精准控制复杂工作流。实现 Reflection、迭代式优化、需要人工介入的流程。Python
