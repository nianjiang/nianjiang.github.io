    英文全称常用简称类似/变体名称定位与核心作用
    DevelopmentDEVDev / Trunk开发环境。开发人员的沙盒，代码变动最频繁，允许频繁崩溃，通常使用 mock 数据。
    Testing / Quality AssuranceTEST / QAFAT (Feature Acceptance Test) / CIT / QC测试环境。QA（测试工程师）进行功能测试、自动化测试、回归测试和提测的专用稳定环境。
    StagingSTGStage / Pre-Production / Pre / 预发环境预发布环境。1:1 高度模拟生产环境（包括配置、架构甚至脱敏后的数据），用于上线前的最后把关。
    ProductionPRODLive / Online / 线上的生产环境。面向真实终端用户的真实环境。对稳定性、安全性和监控要求最高。
